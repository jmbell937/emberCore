# EmberCore Health — Product Brief

## Product Direction
EmberCore Health is a modern detox + rehab EMR SaaS concept designed to replace legacy behavioral-health systems with a faster, cleaner, more role-aware experience.

The first objective is a polished, customer-showable interactive demo that proves the product vision across the full facility workflow.

## Core Problems to Solve
- Ugly, outdated UI
- Too many clicks for common tasks
- Slow charting workflows
- Weak reporting
- Weak scheduling visibility

## Target Market
Detox and rehab treatment centers.

## Primary User Roles
- Admins
- Therapists
- Techs
- Nurses
- BHTs
- Billers
- Executives
- Admissions team

## Version 1 Demo Scope
### Included modules
1. Admissions
2. Charting
3. Scheduling
4. Billing / authorization workflow
5. Reporting / executive dashboards

### Demo goals
- Show a dramatically better UX than Kipu-style legacy systems
- Present believable end-to-end workflows
- Work well on desktop and mobile web
- Look polished enough for customer conversations
- Be structured so it can evolve into a real SaaS product later

## UX Principles
- Role-based dashboards
- Fewer clicks for common actions
- Timeline-first patient chart
- Clear work queues
- Visual scheduling and census views
- Billing context surfaced early
- Modern, readable reporting

## Recommended Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- Responsive web-first design

## Build Phases
### Phase 1 — Interactive demo
- Brand and app shell
- Seeded facility and patient data
- Responsive role-aware dashboard
- Admissions workflow demo
- Patient chart demo
- Scheduling demo
- Billing queue demo
- Reporting demo

### Phase 2 — Deeper realism
- More workflow depth
- More realistic datasets
- Role switching
- More polished UI states
- Richer forms and navigation

### Phase 3 — Production conversion
- Authentication
- Real database
- APIs
- Audit logging
- Tenant isolation
- Permissions model
- Compliance-aware infrastructure

## Positioning
EmberCore Health should feel like a modern operating system for behavioral health treatment centers — not just a prettier clone of an old EMR.
